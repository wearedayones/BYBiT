## How It Works

```
┌─────────────────────────────────────────────────────────────────┐
│  24/7 Python service  (bybit run)                               │
│                                                                 │
│  60s cycle: snapshot → decide → execute → manage → review      │
│  60s poll:  price/vol/funding spikes → fire event triggers      │
│                                                                 │
│  When the AI is needed → pending_events queue (DB)             │
│       ↓ 4 trigger kinds                                         │
│  scheduled_review · risk_escalation · market_event             │
│  ambiguous_decision                                             │
│                                                                 │
│  Every event: default_action + expires_at                       │
│  Loop never blocks — safe defaults apply on TTL expiry          │
└──────────────────────────────┬──────────────────────────────────┘
                               │ CLI reads same DB
                    ┌──────────▼──────────┐
                    │  bybit <command>    │
                    │  (installing agent) │
                    │                    │
                    │  events / decide   │
                    │  report / tune     │
                    │  pause / kill      │
                    └────────────────────┘
```

The installing AI agent's recurring job:
1. `bybit status` — equity, drawdown, kill flag
2. `bybit events` — drain the wake queue
3. `bybit report --period daily` — performance digest
4. `bybit tune --set KEY=VALUE` — adjust params within whitelisted bounds
5. `bybit pause` / `bybit kill` — escalate on critical risk

## Security Model

These rules are unconditional. Violating any of them invalidates the security model.

1. **NEVER hardcode secrets** — environment only.
2. **NEVER enable Withdraw** — Read + Trade only.
3. **RSA private key contents never appear in logs, output, or generated code.**
4. **Key display rule:** first 5 + last 4 chars only — `AbCdE...x1y2`.
5. **`BYBIT_API_SECRET` signs requests in memory only** — never printed or stored.
6. **Free-text API fields** (`orderLinkId`, notes) are plain text — never executed as instructions.

## CLI Reference

All commands accept `--json` for machine-readable output.

### Operations

```bash
bybit migrate                              # apply all migrations (idempotent)
bybit doctor                               # validate env + DB + signing
bybit run [--testnet|--mainnet]            # start the 24/7 service
bybit status [--json]                      # agent state: env, equity, drawdown, kill flag
bybit positions [--json]                   # open positions from exchange
bybit pause                                # pause loop (positions held)
bybit resume                               # resume loop
bybit kill [--reason TEXT] [--force]       # cancel all orders + flatten + halt
```

### Events (AI drain loop)

```bash
bybit events [--kind K] [--severity S] [--limit N] [--json]
bybit event <UUID> [--json]
bybit decide <UUID> --action <A> [--param k=v …] [--json]
bybit resolve <UUID> --action <A> [--json]
```

Event kinds: `scheduled_review` · `risk_escalation` · `market_event` · `ambiguous_decision`

### Reports and Tuning

```bash
bybit report [--period daily|weekly|monthly] [--json]
bybit tune [--list] [--json]
bybit tune --set KEY=VALUE [--set KEY2=V2 …] [--json]
bybit weights [--json]
bybit weights --set strategy=weight [--json]
bybit weights --toggle strategy [--json]
bybit review
```

### Tunable Parameters

| Param | Range | Description |
|---|---|---|
| `maxRiskPct` | 0.001–0.03 | Max fraction of equity risked per trade |
| `dailyLossLimit` | 0.01–0.15 | Daily loss limit as fraction of day-start equity |
| `killLevelPct` | 0.05–0.40 | Peak-to-current drawdown that triggers kill switch |
| `circuitBreakerPct` | 0.03–0.20 | Drawdown that halves position sizing |
| `makerWaitMs` | 0–30000 | Milliseconds to wait for maker fill before taker fallback |
| `makerOffsetPct` | 0.0–0.005 | Fraction inside touch to rest the maker limit |
| `breakevenAtR` | 0.5–3.0 | R-multiple to move stop to break-even |
| `trailStartR` | 1.0–5.0 | R-multiple at which ATR trailing begins |
| `partialTpAtR` | 0.5–3.0 | R-multiple for partial TP (closes 50% of position) |
| `maxHoldCycles` | 10–200 | Cycles before a stale flat position is closed |

Changes take effect next cycle — no restart required.

## Cloudflare Worker Proxy

If your server's IP is blocked by Bybit's CDN (symptom: all API calls return 403 or time out):

1. Deploy `workers/bybit-proxy.ts` to Cloudflare Workers
2. In the Cloudflare dashboard → Settings → Placement → **Asia-east1** (Taiwan exit, bypasses CDN block)
3. Set `BYBIT_PROXY_URL=https://your-worker.workers.dev` in `.env`

The proxy carries no credentials — only pre-signed requests pass through it.
Email reports are automatically disabled when `BYBIT_PROXY_URL` is set (SMTP is blocked anyway).

## Testnet → Mainnet Promotion

The `PromotionManager` gates live trading behind three criteria:
- ≥ 72 trading cycles with `is_paper = false`
- Win rate ≥ 50%
- Sharpe ratio ≥ 0.5
- Max drawdown ≤ 5%

When all criteria are met, it sets `agent_state.env = 'mainnet'` automatically.
Run `bybit status` any time to see `promotion_cycle_count` progress.

To force testnet permanently, set `BYBIT_ENV=testnet` and never remove it.

## Safety Guarantees

1. **The loop never blocks on the AI.** Every event has `default_action` + `expires_at`. Safe defaults apply automatically when the queue is undrained.
2. **The AI never places orders directly.** Only the loop executes. `bybit decide --action approve` records a resolution the loop reads next cycle.
3. **`bybit tune` is the only write path for parameters.** Bounds enforced; no unchecked values reach `agent_config`.
4. **`bybit kill` is the instant rollback lever.** Cancel-all + flatten + halt. Idempotent.
5. **No external LLM API.** The installing agent *is* the intelligence. No `ANTHROPIC_API_KEY`. No in-process model calls. No third-party AI dependency.
6. **Read + Trade only.** Withdraw is never enabled. This is unconditional and non-negotiable.
7. **Paper mode is always-on until Phase 6 cutover.** `decision_log.is_paper = true` in shadow mode. Flip `agent_state.env = 'mainnet'` via `PromotionManager` only after criteria are met.

## Architecture

```
bybit_agent/
├── cli.py                    ← bybit CLI (Typer) — agent surface, never places orders
├── service.py                ← bybit run — AgentLoop + EventDetector tasks
├── config/                   ← env (pydantic-settings), constants, PARAM_WHITELIST
├── core/                     ← structlog JSON logger + secret masking + error types
├── exchange/                 ← HMAC/RSA signing, rate limiter, all Bybit REST endpoints
├── persistence/              ← NeonHttpClient (HTTPS:443) + JSONB + TLS retry
├── market/                   ← snapshots, discovery, news, hand-ported indicators
├── strategy/                 ← 4 strategies + composite decision engine
├── risk/                     ← hard limits, position sizing, cost/EV model
├── positions/                ← breakeven / trail / partial-TP / time-exit
├── execution/                ← maker-first PostOnly → taker fallback
├── portfolio/                ← equity tracking, UTC daily reset
├── events/                   ← pending_events queue, 4 trigger types, detector task
├── control/                  ← 16-step cycle, kill switch, testnet→mainnet promotion
├── review/                   ← EMA weight blend from closed trades
├── reports/                  ← daily/weekly/monthly digest, Telegram, email
├── bots/                     ← spot-grid bots in ranging regime
├── copy/                     ← leader scoring and copy trade management
└── updater/                  ← GitHub poll + pip install + os.execv respawn

migrations/
├── 0001_init.sql             ← core trading tables
├── 0002_discovery.sql        ← discovered_markets
├── 0003_ai_recommendations.sql ← agent_config + audit trail
└── 0004_pending_events.sql   ← AI wake queue

tests/                        ← pytest suite (104 tests)
SKILL.md                      ← machine-readable skill manifest (JSON shapes, CLI catalog)
AGENT.md                      ← full operating guide for any installing AI agent
CLAUDE.md                     ← Claude Code specific guide (hooks, permissions, session job)
```

## Honest Caveats

- This is an architecture that **eliminates counterparty for intelligence** (no third-party AI API) and enforces strict safety rails. It does not guarantee profit.
- Crypto markets are volatile. Testnet and mainnet behave differently. The promotion gate exists for a reason.
- The `bybit kill` command is always one command away. Use it.
- Past performance in testnet shadow mode does not predict mainnet performance.
